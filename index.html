Going live

1 · Host it

Put this file on any static host with HTTPS (Netlify, Vercel, GitHub Pages, Cloudflare Pages — all free tiers work). HTTPS is required for notifications and installing to your home screen.

2 · Wire real stock data

Instead of scraping retailer pages (fragile, and against most retailers' terms), poll established restock-tracking feeds and match them against your watchlist:
  • NowInStock — per-product pages with RSS feeds covering Pokemon Center, Target, Walmart, Best Buy and more
  • HotStock / Zoolert-style trackers — similar alert feeds for TCG sealed product
  • Retailer storefront APIs where offered (e.g. Best Buy has an official products API with availability fields)
  • Marketplaces — for eBay, use official saved searches (they can email or app-notify on new listings under a price); this app's eBay buy-links already pre-apply your top price as a filter. Mercari and BGG listings can be polled the same way as retail feeds
A small serverless function (Cloudflare Worker or Netlify Function) fetching a feed every 1–2 minutes and diffing "out of stock → in stock" is all the backend logic you need.

3 · True background push

Notifications that arrive with the app closed need a push service. The standard free stack:
  • A service worker file (about 20 lines) registered by this page
  • Web Push via your serverless function using the web-push npm library and a VAPID key pair, or Firebase Cloud Messaging if you prefer a console UI
  • Your stock-checking function calls the push endpoint whenever a watched item flips to in stock
On iPhone, add the app to your home screen first — iOS only delivers web push to installed web apps.

4 · What the buy button does

Every alert's Go buy button deep-links straight to that product at the retailer, skipping browsing. Checkout stays in your hands — this app's speed advantage is being told the moment stock lands, not automated purchasing (which retailer terms prohibit and which gets accounts and IPs banned).
